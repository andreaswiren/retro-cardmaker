Artwork Scraping & Local Media

Libretro CDN
Enable Boxart Syncing during Copy
Matches each ROM and places cover image in your launcher's art folder.

Media Pipeline Hierarchy:

  1. Local Cache First: Copies existing boxarts found in Imgs/ or _retroarch_thumbnails/.
  2. Libretro CDN Fallback: If missing, downloads official PNG boxarts from GitHub CDN (100% free, no API keys).
  3. Illegal Character Normalization: Replaces & * / : ` < > ? \ | " with Libretro standard _.
  4. Target Frontend Renaming: Formats to .png, -image.png, or covers/.png.
